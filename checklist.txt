Phase 0–1: 문서 계층(메타/URI 안정화)
1) 스키마/URI 문서가 최신인가

파일: docs/schema_and_uri.md

확인 포인트

contentType enum에 appendix 포함

Dual URI: uri(URN) + articleUri/clauseUri(HTTP) 병행 저장 규정

프로그램 코드 대문자 표준: UG, MS, PHD, IME_MS, IME_PHD

점검

눈검(파일 열어 2.1 스키마/URN+HTTP 전략 문단 확인)

2) 인덱싱 시 스키마 강제/정규화가 되는가

파일: add_document.py, utils.py

확인 포인트

utils.attach_uri_and_schema() 같은 공통 유틸로 URN+HTTP URI, program/cohort, contentType, md5, sourceFile를 보강

add_document.py에서 실제로 그 유틸을 호출해 모든 레코드에 적용

점검 (WSL/Windows 공통)

# 유틸에 핵심 키워드가 있는지
grep -n "attach_uri_and_schema" -n utils.py add_document.py
grep -n "articleUri" utils.py add_document.py
grep -n "contentType" utils.py add_document.py
grep -n "md5" utils.py add_document.py


샘플 JSON 1개를 add_document로 통과시켜 출력 메타에
schema_version / uri / articleUri / contentType / program / cohort / sourceFile / md5
가 들어오는지 확인.

3) PDF 청크 생성 메타가 표준키로 들어오는가

파일: process_pdf.py

확인 포인트

청크 메타에 contentType, page, articleNumber/articleTitle, sourceFile, md5 세팅

표는 contentType:"table"로 저장(레거시 content_type도 유지 가능)

점검 (WSL에서 실행)

python3 process_pdf.py --input-dir "./row data" --output-dir "./new data"
head -n 50 "./new data/*chunk*.json"
# → metadata.contentType == "table" or "text", sourceFile/md5/page 존재 확인

4) 테이블 업그레이드 후에도 스키마가 유지되는가

파일: upgrade_tables.py

확인 포인트

PDF에서 표 재추출 → JSON text를 Markdown으로 교체

메타 표준화: metadata.contentType="table", page(int), sourceFile, md5

점검

python3 upgrade_tables.py --json-dir "./new data" --pdf-dir "./row data" --dry-run
# 로그에 upgraded / skipped 사유가 명확히 출력되면 OK

5) 자동 스키마 검증(6개 체크리스트)

파일(있으면): validate_metadata.py (미니 검증 스크립트)

확인 포인트

폴더를 훑어 아래 6항목을 리포트:

schema_version 존재

articleUri/clauseUri가 HTTP(S)

versionDate + effectiveFrom/Until 키 존재(없으면 null)

program/cohort 정규형 값

contentType ∈ {text, table, annex, appendix}

(있다면) overrides/cites/hasExceptionFor 리스트 타입

점검

스크립트가 있으면 실행, 없다면 임시로 한 파일 열어 HTTP URI, contentType, program 대문자를 눈검.

Phase 5: KG PoC
13) OWL/SHACL 스캐폴딩이 최소 요건을 충족하는가

파일: ontology/uni.ttl, ontology/shapes.ttl

최종 OK 기준(요약)

문서 계층: docs/schema_and_uri.md 최신 + add_document.py/utils.py/process_pdf.py/upgrade_tables.py가 동일 스키마/URI 규칙을 적용한다.
